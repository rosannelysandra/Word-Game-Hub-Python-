# 🎮 Word Game Hub

A Python-based desktop application that combines multiple word-based games into a single interactive GUI. The project is built using **Tkinter** and **ttkbootstrap**, with a simple and modern interface.

## 📌 About the Project

Word Game Hub is a collection of interactive word games designed to improve vocabulary, typing speed, and word-solving skills.

The application provides a central menu from which users can choose between:

- 🟩 Wordle
- ⌨️ Typing Speed Test
- 🔤 Anagram Solver

The application uses randomly selected words and sentences to provide a different experience during each session.

## ✨ Features

### 🟩 Wordle
- Choose a word category:
  - Fruits
  - Animals
  - Countries
- Guess the hidden word within 6 attempts.
- Provides visual feedback for each letter:
  - 🟩 Correct letter and position
  - 🟨 Correct letter but wrong position
  - ⬜ Letter not present in the word
- Displays a win or game-over message.

### ⌨️ Typing Speed Test
- Generates a random sentence.
- Measures the time taken to type the sentence.
- Calculates typing speed in **Words Per Minute (WPM)**.
- Checks whether the entered sentence matches the given sentence.

### 🔤 Anagram Solver
- Randomly selects a word from one of the available categories.
- Scrambles the letters of the selected word.
- Allows the user to enter their guess.
- Provides immediate feedback on the answer.
